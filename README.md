# Estatística: Conceitos e Experimentações — GCT018

Site estático de apoio à disciplina GCT018 do ICTIN/UFLA.

## Publicação no GitHub Pages
1. Crie um repositório público, por exemplo `estatistica-gct018`.
2. Envie todo o conteúdo desta pasta preservando `assets/` e `conteudos/`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**.
4. Salve e aguarde o workflow `pages build and deployment`.

As fórmulas usam MathJax. Portanto, o navegador precisa de acesso à internet para carregar a biblioteca e as fontes Google.
