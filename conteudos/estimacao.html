INFERÊNCIA ESTATÍSTICA

Estimação

Estimar é usar informação amostral para quantificar um parâmetro desconhecido e a incerteza associada.

1. Estimador e estimativa

Um estimador \(\hat\theta=T(X_1,\ldots,X_n)\) é uma variável aleatória usada para aprender sobre o parâmetro \(\theta\). Depois de observar os dados, seu valor numérico é uma estimativa.

2. Propriedades

Entre as propriedades usuais estão não viés, consistência e eficiência. Um estimador é não viesado quando

\[ E(\hat\theta) = \theta. \]

3. Máxima verossimilhança

A função de verossimilhança é

\[ L(\theta;\mathbf{x}) = \prod_{i=1}^{n} f(x_i;\theta). \]

O estimador de máxima verossimilhança é

\[ \hat\theta_{MV} = \underset{\theta}{\arg\max} \; L(\theta;\mathbf{x}). \]

4. Intervalo de confiança

Um intervalo de confiança é construído por um procedimento aleatório que, em repetidas amostragens sob o modelo, cobre o parâmetro com frequência especificada.

Para média normal com \(\sigma\) desconhecido,

\[ \bar{x} \pm t_{1-\alpha/2,n-1} \frac{s}{\sqrt{n}}. \]
Após observar a amostra em uma abordagem frequentista clássica, o parâmetro é fixo. Assim, não se interpreta um IC de 95% como “há 95% de probabilidade de \(\mu\) estar neste intervalo”.

5. Intervalos de confiança por bootstrap

O bootstrap aproxima a distribuição amostral de uma estatística por reamostragem com reposição da amostra observada.

A partir da amostra

\[ \mathbf{x} = (x_1,\ldots,x_n), \]

geram-se \(B\) reamostras bootstrap:

\[ \mathbf{x}^{*(1)}, \ldots, \mathbf{x}^{*(B)}. \]

Cada reamostra possui tamanho \(n\). Em cada uma, calcula-se

\[ \hat\theta^{*(b)} = T\!\left( \mathbf{x}^{*(b)} \right), \] \[ b=1,\ldots,B. \]

A distribuição empírica das \(B\) estimativas bootstrap aproxima a distribuição amostral de \(\hat\theta\).

Termos. \(n\) é o tamanho da amostra; \(B\) é o número de reamostragens; \(T(\cdot)\) é a estatística de interesse; \(\hat\theta\) é a estimativa original; \(\hat\theta^{*(b)}\) é a estimativa na reamostra \(b\).

IC bootstrap percentil

\[ \left[ \hat\theta^*_{(\alpha/2)}, \; \hat\theta^*_{(1-\alpha/2)} \right]. \]

\(\alpha\) é o nível de significância e \(\hat\theta^*_{(q)}\) é o quantil de ordem \(q\) das estimativas bootstrap. O percentil é simples, mas assimetria, viés, amostras pequenas ou dependência podem exigir métodos como BCa ou esquemas de reamostragem que preservem a estrutura dos dados.

R · IC percentil para a média 
set.seed(123)

x <- c(
  12.1, 11.8, 12.5, 12.0,
  11.9, 12.4, 12.2, 12.3
)

B <- 10000

medias_boot <- replicate(
  B,
  mean(
    sample(
      x,
      length(x),
      replace = TRUE
    )
  )
)

quantile(
  medias_boot,
  c(.025, .975)
)
Aplicação. O princípio pode ser usado para média, mediana, diferenças, coeficientes de regressão e outras estatísticas. Em dados agrupados, pareados, temporais ou espaciais, a unidade de reamostragem deve respeitar a dependência.
